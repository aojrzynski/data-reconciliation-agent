# Future Work

This list is intentionally grounded. These are possible improvements, not commitments.

- Richer date/datetime tolerance options where business rules require them.
- Composite key support with explicit deterministic semantics.
- Configurable output formats beyond current trace/report/CSV defaults.
- Larger dataset performance profiling and optimization guidance.
- Database connectors at the intake layer while preserving the core engine.
- Better HTML report formatting for easier sharing.
- Optional packaged CLI release workflow.
- Stronger prompt/evaluation harness for optional LLM polish quality checks.
