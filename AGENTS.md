# Coding Agent Guidance

## Core rules

- Deterministic checks are the source of truth.
- Keep code readable and direct.
- Avoid unnecessary abstractions.
- Document assumptions in code and docs.
- Do not add frameworks without clear justification.
- Preserve CLI-first and local-first design.
- Update docs when behavior changes.
- Add tests for every new behavior.

## Practical expectations

- Prefer explicit function names over clever patterns.
- Keep module responsibilities narrow and obvious.
- Ensure output artifacts remain easy to inspect.
- Treat agent mode as an orchestrator, not a judge.
